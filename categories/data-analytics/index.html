Airline Sentiment Analysis: Interactive Exploration with Streamlit

Executive summary This case study describes an interactive Streamlit app for exploring tweets about airlines, grouped by positive, negative and neutral sentiment. Users can inspect sentiment distributions, filter by time and location, compare airlines and explore frequently used terms. The project focuses on exploratory analysis and visualization of sentiment-labeled tweets. The original article does not document training or evaluating a new sentiment classification model. Its use of a tweet dataset should not be confused with verified real-time social media ingestion.

Sales and Returns Analytics: Building a Power BI Dashboard

Executive summary This project explores a Power BI dashboard for sales and product returns at a fictional electronics retail chain. The solution transforms XLSX source files with Power Query and organizes three complementary analytical views: overall performance, product and brand performance, and returns. The objective is to make business indicators easier to explore and support discussions about commercial performance and operational improvements. The project is a portfolio case study; it does not report production adoption or independently measured savings.
