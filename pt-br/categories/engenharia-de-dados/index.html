Pipeline ETL em Python: unificando dados CSV, JSON e XML

Resumo executivo Este projeto demonstra um fluxo ETL (Extract, Transform, Load) desenvolvido em Python para consolidar registros armazenados em arquivos CSV, JSON e XML. O processamento padroniza os dados e gera dois artefatos: transformed_data.csv e log_file.txt. O estudo de caso apresenta as principais decisões de engenharia: integração de formatos diferentes, regras de transformação, execução reproduzível e rastreabilidade por logs. Trata-se de um pipeline didático de pequeno porte, e não de uma plataforma de produção.
