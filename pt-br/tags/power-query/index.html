Análise de Vendas e Devoluções: Dashboard em Power BI

Resumo executivo Este projeto apresenta um dashboard em Power BI para análise de vendas e devoluções de uma rede fictícia de lojas de eletrônicos. A solução prepara arquivos XLSX com Power Query e organiza três perspectivas: desempenho geral, produtos e marcas, e devoluções. O objetivo é facilitar a leitura de indicadores comerciais e apoiar discussões sobre desempenho e melhorias operacionais. Trata-se de um projeto demonstrativo de portfólio, sem evidência de implantação real ou economia financeira mensurada.
